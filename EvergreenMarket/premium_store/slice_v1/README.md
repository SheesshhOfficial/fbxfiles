# You want it You get it — premium pantry vertical slice v1

This is a Blender art-and-source-contract approval stage, not the complete store or a ready-to-run Unreal package. The approved 64 × 56 m floor plan stays separate. The technical EvergreenMarket repository folder is retained; the store display name is exactly **You want it You get it**.

## What is included

- A refined pantry segment: warm wood/black metal shelf bays, pale stone surfaces, price rails, visible pendant fixtures and matching positional area lights.
- Ten fictional Morrow & Vale product designs plus a basket asset. Repeated merchandise is separate, stable-ID placement data sharing canonical mesh assets.
- 488 eligible placements across 11 eligible assets. Every one is marked for individual StaticMeshActor import with the Prop tag, rather than only one representative per SKU.
- Six shelf fixture placements and eight physical context placements, including floor, walls, ceiling and display console.
- Twenty canonical assets and 42 authored convex collision hulls. Intentional nonblocking surface/decorative details are explicitly inventoried.
- Packed-texture Blender source, repeatable authoring scripts, export-intent manifest and independent source-validation reports.

## What the checks establish

Independent read-only source checks validate unique placement IDs, shared canonical mesh data, unit scales, material consistency, hull naming/geometry, source transforms, collision coverage and selected openings. At the reviewed checkpoint: 243 closed render shells are outward; all 42 hulls are closed, convex and outward; 13 basket/shelf-opening probes are clear. Open printed/lettering surfaces are intentional.

These are source checks, not a guarantee of gameplay collision. The Character root/capsule and current 100 cm-radius first-hit interaction need actual Unreal tests. No Unreal import, ten-player multiplayer or frame-rate validation is claimed.

## Before Unreal delivery

This stage does not include a tested FBX exporter/importer. Procedural Blender shading must be baked or rebuilt as explicit Unreal materials. Blender light energy is recorded in watts; Unreal photometric intensity needs explicit conversion/tuning and validation, not a blind numeric copy. Asset FBXs should each contain one canonical render mesh with its associated collision hulls. Every eligible placement must become its own tagged StaticMeshActor, while sharing mesh/material assets.

Preserve the existing working project. The later integration must create new versioned assets/map, save/reload and check all placement/collision counts, then test the smallest can, medium carton, basket and larger approved disguises against real movement and first-hit selection.

## Approval requested

Review the aisle atmosphere, wood/metal/stone finish, packaging quality and product closeups. The user approved the product style and authorized five documented full-store improvement passes. This slice is the frozen source/visual checkpoint for that continuation; it is not itself the finished full store.
